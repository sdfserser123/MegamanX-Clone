# Mega Man X Clone

![Project Status](https://img.shields.io/badge/Project%20Status-In%20progress-orange)
![Engine](https://img.shields.io/badge/Unity-6-blue?logo=unity)
![Language](https://img.shields.io/badge/Language-C%23-green?logo=csharp)

A 2D platform action game built with **Unity 6** to faithfully recreate the core mechanics and gameplay of the iconic first *Mega Man X* game. Players control X through Chill Penguin's stage, fighting enemies, mastering movement mechanics, and powering up to defeat the final boss.

## Core Features

* **Combat & Weapon Systems:** * **X-Buster:** Shoot standard energy bullets to defeat enemies.
    * **Charge Shot:** Hold down the attack button to charge up and unleash a massive, high-damage blast.
* **Advanced Movement System:** * Smooth side-to-side running and jumping.
    * **Wall Mechanics:** Wall sliding and wall jumping to navigate vertical terrain.
    * **Dash:** Quick ground dash for gaining momentum.

---

## Tech Stack & Tools

* **Game Engine:** Unity 6
* **Programming Language:** C#
* **Art & Animation:** Adobe Photoshop (Sprites & Textures)
